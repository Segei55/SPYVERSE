# SPYVERSE — Шпионская игра для компании друзей 🕵️‍♂️

**SPYVERSE** — это современная многоплатформенная игра в жанре социального дедуктивного детектива («Шпион»). Участники партии получают роли на секретном объекте. Все мирные жители знают локацию и свою профессию, а шпион не знает объект и пытается выяснить его по вопросам других игроков, сохраняя инкогнито.

Игра готова к сборке под **Windows** (установщик `.exe` и portable), **Linux** (AppImage, DEB), **Android** (APK) и в виде **автономного выделенного сервера** для домашнего ПК.

---

## 🚀 Особенности SPYVERSE

- **Сетевой клиент-серверный мультиплеер:** хост создаёт комнату на своём ПК или сервере, генерируется 6-значный буквенный код.
- **Подключение по LAN, Hamachi, Radmin VPN:** прямое подключение без зависимости от платных облачных серверов.
- **Встроенный офлайн-режим (Pass & Play):** игра на одном устройстве (ПК, планшет или телефон) с приватным просмотром роли и передачей гаджета по кругу.
- **Голосовая связь WebRTC:** живой микрофон, режим Push-To-Talk (PTT по пробелу или кнопке), индикаторы говорящих игроков, шумоподавление.
- **19 полных тематических наборов локаций:**
  1. *Обычные локации (Классика)*
  2. *Minecraft*
  3. *Clash Royale*
  4. *Dota 2*
  5. *Counter-Strike 2*
  6. *Roblox*
  7. *Terraria*
  8. *Stardew Valley*
  9. *Among Us*
  10. *Genshin Impact*
  11. *Школа*
  12. *Профессии*
  13. *Путешествия*
  14. *Космос*
  15. *Фэнтези*
  16. *Ужасы*
  17. *История*
  18. *Еда и рестораны*
  19. *Интернет-культура и мемы*
- **Встроенный редактор наборов:** создание своих локаций и ролей, проверка дубликатов, валидация по схеме Zod, экспорт и импорт файлов `.json`.
- **Игровые модификаторы:** «Блиц-раунд», «Шёпот подозрений», «Слепое голосование», «Радиопомехи».
- **Синтезатор звуковых эффектов:** процедурные звуки на Web Audio API без внешних аудиофайлов.
- **Текстовый чат:** история сообщений сохраняется на стороне хоста в защищённой системной директории.

## 💻 Установка и быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск приложения в режиме разработки
```bash
npm run dev
```
Откройте в браузере: `http://localhost:3000`. Приложение запустит объединённый Full-Stack сервер с React-клиентом и Socket.IO мультиплеером.

### 3. Запуск отдельного выделенного сервера (Dedicated Server)
```bash
npm run start:server
```
Сервер запустится на порту `3001` (или порту из переменной `PORT`), выведет в консоль список всех доступных физических и виртуальных IP-адресов вашего ПК (LAN, Hamachi, Radmin) и откроет Web Dashboard по адресу `http://localhost:3001`.

## 🌐 Как пригласить друзей (LAN / Hamachi / Radmin VPN)

### Локальная сеть (Wi-Fi / Роутер):
1. Хост нажимает «Создать комнату».
2. В окне «Свой сервер & Сетевая игра» смотрит свой локальный IP (например, `192.168.1.50`).
3. Друзья в окне «Настройки» вводят адрес хоста: `http://192.168.1.50:3000` и нажимают «Сохранить».
4. Затем нажимают «Войти по коду» и вводят 6-значный код комнаты (например, `SPY789`).

### Виртуальная сеть (Hamachi / Radmin VPN):
1. Хост и друзья подключаются к одной комнате в Hamachi или Radmin VPN.
2. Друзья копируют IP-адрес хоста из Hamachi (`25.x.x.x`) или Radmin (`26.x.x.x`).
3. В настройках игры вводят адрес `http://<IP-ХОСТА>:3000`.
4. Вводят код комнаты и играют через интернет без открытия портов.

## 📦 Сборка под платформы

### Сборка Windows (`.exe` установщик и Portable)
```bash
npm run build
npm run --workspace=@spyverse/desktop build
npx electron-builder --config apps/desktop/electron-builder.json --win
```
Готовые файлы создаются в каталоге `dist-electron/`:
- `SPYVERSE Setup 1.0.0.exe` (NSIS инсталлятор с ярлыками)
- `SPYVERSE 1.0.0.exe` (портативная сборка без установки)

### Сборка Linux (`AppImage` и `.deb`)
```bash
npm run build
npm run --workspace=@spyverse/desktop build
npx electron-builder --config apps/desktop/electron-builder.json --linux
```
Готовые файлы создаются в каталоге `dist-electron/`:
- `SPYVERSE-1.0.0.AppImage`
- `spyverse_1.0.0_amd64.deb`

### Сборка Android APK
```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```
Готовый файл создаётся по пути:
`android/app/build/outputs/apk/debug/app-debug.apk`.

### Сборка Standalone Сервера (для хостинга на ПК без Vite)
```bash
npm run build
npm run build:server
node dist-server/spyverse-server.cjs
```
Сервер сам раздаёт собранный веб-клиент, поэтому друзья открывают игру по адресу `http://IP:3001`.

### Запуск сервера одним файлом (Windows)
После установки игры запустите `server.bat` в папке SPYVERSE (или `server.bat 4000`, чтобы выбрать порт). Если порт занят, скрипт автоматически проверит следующие порты. Установщик кладёт рядом с игрой файл сервера и веб-клиент; Node.js для такой установленной версии не нужен — при его отсутствии сервер запустится через Electron. Настольная игра также запускает локальный сервер автоматически, если отдельный сервер ещё не работает.

В корне исходного проекта `server.bat` по-прежнему может подготовить зависимости и собрать клиент. Если рядом лежит готовый `spyverse-server.cjs` (например, из артефакта GitHub Actions), используется он.

### Сборки в GitHub Actions
| Workflow | Артефакт |
|---|---|
| `desktop.yml` | Windows: `*.exe` (установщик и portable); Linux: `*.AppImage`, `*.deb` |
| `android.yml` | `app-debug.apk` (Java 21, Capacitor генерирует проект в `apps/mobile/android`) |
| `server.yml` | `spyverse-standalone-server` (`spyverse-server.cjs`, `dist/`, `server.bat`) |
| `ci.yml` | Проверка типов, тесты, сборка клиента |

## ❓ Устранение распространённых проблем

1. **Друзья не могут подключиться к серверу по IP:**
   - Проверьте, что брандмауэр Windows / Linux не блокирует входящие подключения на порт `3000` или `3001`.
   - Если играете через интернет без белого IP, используйте **Radmin VPN** или **Hamachi**.
2. **Не работает голосовая связь:**
   - Предоставьте разрешение на использование микрофона в браузере или настройках операционной системы.
   - В окне голосовой панели нажмите «Микрофон вкл» или используйте клавишу `Пробел` в режиме Push-To-Talk.
3. **Ошибка при импорте своего набора JSON:**
   - Убедитесь, что в наборе минимум 4 локации, в каждой локации минимум 3 роли, и нет дублирующихся названий.
